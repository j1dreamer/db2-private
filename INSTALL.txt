DB2 ENG SSS/SP + GM V2 - MATCHED CLIENT AND SERVER

1. Download the eng-sp-sss source ZIP into a NEW folder. Stop the old server.
2. Install Python 3.10+ and Node.js LTS. Run start.bat from the new folder.
3. Run Download-Clients.bat; it creates the complete APK and unsigned IPA automatically.
   No old APK, Git or manual joining is required. Keep the cache to resume/reuse downloads.
4. Put DB2-ENG-SPSSS-GM.apk beside Install-Android.bat. Start BlueStacks and enable ADB.
   Run Install-Android.bat; enter the address BlueStacks shows (often 127.0.0.1:6610).
5. Game server: http://127.0.0.1:20003. Register a NEW account if using a new database.
6. Admin uses the same URL. Its token is in data/admin-token inside this NEW server folder.
7. Grant GM in Admin > Players. The NEW client shows GM below Speed.
   GM includes a searchable item/role list, quantities, player/role levels, VIP and resources.

Health must show build eng-sp-sss-gm-v2, schema 30. Update BOTH server and client.
Native code and development signing identity stay original. IPA is unsigned and must
be legitimately signed on your Mac. Use an actually reachable LAN/Tailscale address
on an iPhone; 127.0.0.1 there does not refer to your laptop.

Gameplay/data follow ENG, including original S/SS/SSS/SP groups. Private backend rules,
GM, transport, translation additions and UI repairs are explicitly authored project code.
