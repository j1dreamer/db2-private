DB2 ENG SSS/SP + GM - V6 SERVER EVENT OBJECTIVES

1. Stop the old server. Back up and preserve your data folder.
2. Extract the eng-sp-sss source ZIP into a new folder, then copy your existing
   ENG data folder there if you want to retain accounts and inventories.
3. Install Python 3.10+ and Node.js LTS. Run start.bat from the new folder.
4. Health must show eng-sp-sss-event-goals-v6, profile schema 30.
5. Existing BoxInfo APK/IPA stay unchanged for this server/web update.
   If you need the matched clients, Download-Clients.bat creates the full files:
   DB2-ENG-SPSSS-BoxInfo.apk and DB2-ENG-SPSSS-BoxInfo-unsigned.ipa.
6. For BlueStacks, enable ADB and run Install-Android.bat with the APK beside it.
   Use the emulator's actual ADB port; game server is http://127.0.0.1:20003
   when the matching adb reverse is active.
7. Admin uses the same server URL. Its token is in data/admin-token.
   Events now support Gem spending, adventure wins/sweeps and normal/advanced
   draws. Select a goal/threshold and reward items with images in the event form.
   Transactions count from the server upgrade forward, with no historical backfill.
8. Ubuntu + systemd deployment: UBUNTU.md. Android server: TERMUX.md.

IPA is unsigned and needs legitimate signing on your Mac. On an iPhone, use
an actually reachable LAN/Tailscale server address; 127.0.0.1 is the phone itself.
Gameplay/data follow ENG, including original S/SS/SSS/SP groups. Private backend
rules and these event conditions are authored project code. Native end-to-end
Android/iPhone play for this update remains unverified.
